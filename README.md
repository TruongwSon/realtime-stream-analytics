# Real-Time Stream Analytics System


## Objective

An online application using Real-Time Updates technique for continuous financial data monitoring.


## Method

The system receives live Bitcoin price data and performs statistical stream analysis.


## Algorithm

Rolling Z-score:

Z = (Xt - μ) / σ


Anomaly detection:

|Z| > 2


## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Binance API


## Deployment
